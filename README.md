# 회사 시스템을 클로드에 연결하는 스킬 — `company-mcp-connect`

> 새 프로그램이나 웹페이지를 만들지 마세요. **이미 있는 회사 시스템(DB·문서 저장소)을 MCP 로 클로드에 연결**하면 됩니다.
> 단, **AI 가 볼 수 있는 것과 할 수 있는 것은 회사가 정합니다.** 이 스킬은 그 결정을 대신 내리지 않고, 질문으로 끌어내서 코드와 DB 권한에 박아 넣도록 안내합니다.

---

## 영상 더보기용 짧은 안내

```
📦 「회사 시스템 → 클로드 연결」 스킬 받기: https://github.com/BinaryHo-P/company-mcp-connect
① 압축을 풀어 company-mcp-connect 폴더를 ~/.claude/skills/ 에 넣으세요 (Claude 앱이면 설정 → 스킬에서 company-mcp-connect.skill 업로드).
② Claude Code 에서 "우리 회사 DB를 클로드에 연결하고 싶어" 라고 말하면 질문 → 도구 목록 → 보안 점검 → 서버 코드 → 등록 → 시험 순서로 안내합니다.
③ PostgreSQL·MySQL·SQL Server / GCS·S3·Azure·로컬 폴더 지원. 예시는 모두 가상 회사 데이터입니다.
④ 처음엔 꼭 시험용 DB 에서, 읽기 전용으로 시작하세요.
```

---

## 이 스킬이 하는 일

클로드와 대화하면서 아래 여섯 단계를 차례로 진행합니다. 각 단계 끝에서 확인을 받고 넘어갑니다.

| 단계 | 하는 일 | 대표님이 정할 것 |
|---|---|---|
| 1. 질문 | 어떤 DB·저장소인지, 직원이 **실제로 물을 질문**이 무엇인지, 무엇을 가릴지, 쓰기를 허용할지 묻습니다 | 업무 질문 5~10개, 가릴 정보 |
| 2. 도구 목록 초안 | 질문 하나하나가 어떤 "도구"로 답해지는지 표로 보여 줍니다 | 열 도구 / 일부러 열지 않을 것 |
| 3. 보안 체크리스트 | 접속 계정, 가림, 쓰기 잠금, 기록(감사 로그)을 점검표로 채웁니다 | 접속 방식, 쓰기 여부 |
| 4. 서버 코드 | 템플릿을 복사해 회사에 맞게 고치고, DB 에 만들 "AI 전용 창구(뷰)" SQL 을 씁니다 | 실행은 DB 담당자가 시험용 DB 에서 |
| 5. 클로드 등록 | Claude Code 또는 Claude Desktop 에 연결하는 방법을 안내합니다 | — |
| 6. 시험 | 연결 확인 → 안전장치 확인 → 실제 질문 순서로 시험합니다 | 결과 확인 |

**용어 한 줄 풀이**
- **MCP 서버**: 클로드와 회사 시스템 사이에 두는 작은 중간 프로그램. 정해 둔 질문(도구)만 받습니다.
- **도구**: "현장 찾기", "이번 주 마감 목록"처럼 클로드가 부를 수 있는 기능 하나.
- **뷰**: 원본 표에서 보여 줄 칸만 골라 만든 창. 전화번호 칸을 뷰에 넣지 않으면 AI 는 영영 볼 수 없습니다.
- **권한 축소 롤**: 그 뷰만 읽을 수 있게 만든 전용 DB 계정.

## 기본으로 들어 있는 안전장치

1. **만능 도구 없음** — "아무 SQL 이나 실행" 같은 도구를 만들지 않습니다. 정해 둔 질문만 받습니다.
2. **관리자 계정이면 서버가 아예 뜨지 않음** — 시작할 때마다 접속 계정을 검사합니다(관리자·소유자·직접 쓰기 권한이 보이면 거절). 원본 표가 정말 막혀 있는지도 매번 확인합니다.
3. **가림 두 겹** — 1차는 DB 뷰(연락처·금액 칸을 아예 빼고, 비공개 건 이름은 가림), 2차는 서버가 내보내기 직전에 이메일·전화번호를 한 번 더 가립니다.
4. **쓰기는 기본 꺼짐** — 켜도 "미리보기 → 사람 승인 → 확정" 순서이고, 같은 등록을 두 번 하지 못하게 막습니다(중복 방지 원장).
5. **기록** — 누가 언제 어떤 질문을 했고 몇 건이 나갔는지 감사 로그에 남습니다(고객 정보 본문은 적지 않음).
6. **비밀번호 대신 클라우드 로그인** — 클라우드 DB 는 Google·AWS·Azure 계정 로그인으로 붙도록 권합니다. 노트북에 비밀번호가 남지 않고, 기록자가 증명됩니다.
7. **필요 없는 키는 지움** — 서버가 시작할 때 쓰지 않는 다른 서비스 키·DB 주소를 환경에서 지웁니다.

## 설치

### Claude Code (권장 — 서버 코드를 만들고 시험까지 직접 해 줍니다)
1. 이 저장소에서 초록색 **Code → Download ZIP** 으로 받아 압축을 풉니다.
2. `company-mcp-connect` 폴더를 아래 위치에 복사합니다.
   - Mac: `~/.claude/skills/company-mcp-connect/`
   - Windows: `C:\Users\<사용자>\.claude\skills\company-mcp-connect\`
3. Claude Code 를 새로 열고 "우리 회사 DB 를 클로드에 연결하고 싶어"라고 말합니다.

### Claude 앱(claude.ai · Desktop)
설정 → 기능(Capabilities) → 스킬 → `company-mcp-connect.skill` 업로드. 설계·점검표 단계는 그대로 쓸 수 있지만, 서버를 실제로 만들고 돌리는 단계는 내 PC 에서 명령을 실행해야 하므로 Claude Code 가 편합니다.

### 준비물
- Node.js 20 이상 (https://nodejs.org 에서 LTS 설치)
- 회사 DB 에 "전용 계정과 뷰"를 만들어 줄 사람(사내 담당자 또는 시스템 업체)
- (선택) Docker — 회사 DB 를 건드리기 전에 가상 DB 로 먼저 돌려 볼 때

## 지원 범위와 시험 결과

| 구분 | 지원 | 이 배포본에서 실제로 확인한 것 |
|---|---|---|
| DB | PostgreSQL · MySQL · SQL Server | **PostgreSQL 16, MySQL 8.4**: 가상 DB 로 도구 목록·읽기·쓰기·중복 차단·관리자 거절까지 확인 / SQL Server: **미시험**(코드·SQL 은 들어 있음) |
| 인증 | 비밀번호 롤 · GCP IAM · AWS IAM · Azure AD | **비밀번호 롤(localhost)** 확인 / GCP·AWS·Azure 인증: 패키지 로딩과 오류 안내까지만, 실제 계정 접속은 **미시험** |
| 문서 저장소 | 로컬 폴더 · GCS · S3 · Azure Blob | **로컬 폴더** 확인(폴더 밖 경로·링크 차단 포함) / GCS·S3·Azure: **미시험** |
| 클로드 연동 | Claude Code · Claude Desktop | Claude Code 로 실제 질문 3개 → 맞는 도구 선택, 매뉴얼 근거 표시, 전화번호 요청 거절 확인 |

미시험 조합은 처음 쓸 때 시험용 인스턴스에서 먼저 확인하세요. 스킬도 그렇게 안내합니다.

## 꼭 지켜 주세요

- **운영 DB 에서 처음 시험하지 마세요.** 시험용 DB 나 가상 DB 에서 통과한 뒤 연결합니다.
- **처음에는 읽기만.** 쓰기는 한 가지 동작으로 좁혀서, 충분히 써 본 뒤에 켭니다.
- 클라우드 권한 변경이나 DB 설정 변경은 담당자가 직접 실행하세요(스킬은 명령과 영향만 설명합니다).
- 이 스킬과 템플릿은 출발점입니다. 실제 회사 데이터에 적용하기 전에 기술 담당자의 검토를 권합니다.
