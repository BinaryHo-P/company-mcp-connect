# 욕실 방수 공사 절차 (가상 회사 새봄인테리어 예시 매뉴얼)

> 이 문서는 스킬 시연용으로 지어낸 매뉴얼이다.

## 1. 철거 후 바닥 점검
- 기존 타일을 걷어 낸 뒤 바닥 균열을 사진으로 남긴다.
- 균열 폭이 2mm 를 넘으면 현장 소장에게 보고하고 보수 범위를 정한다.

## 2. 방수층 시공
- 프라이머 → 액체 방수제 2회 도포. 벽은 바닥에서 30cm 이상 올린다.
- 도포 사이 간격은 최소 4시간.

## 3. 담수 시험
- 방수층이 마르면 물을 5cm 채우고 24시간 둔다.
- 아래층 천장에 물 자국이 없으면 통과. 결과를 일정표의 '방수층 양생 확인' 항목에 완료로 표시한다.

## 4. 타일 시공
- 담수 시험 통과 전에는 타일을 붙이지 않는다.
